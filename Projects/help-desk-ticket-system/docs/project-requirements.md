# Help Desk Ticket System

## Project Goal

Build a modern full-stack IT Help Desk Ticket System that allows employees to report technical problems while enabling IT staff to manage and resolve support requests.

---

# User Roles

## Employee

- Register account
- Login
- Create tickets
- View own tickets
- Edit open tickets
- Comment on tickets
- Close resolved tickets

---

## Technician

- View assigned tickets
- Update ticket status
- Add internal notes
- Comment
- Change priority
- Resolve tickets

---

## Administrator

- Manage users
- Manage departments
- Manage categories
- Assign technicians
- View reports
- Manage system settings

---

# Ticket Information

Every ticket contains:

- Ticket Number
- Title
- Description
- Category
- Priority
- Status
- Created Date
- Last Updated
- Created By
- Assigned Technician
- Attachments (future version)
- Comments

---

# Ticket Status

- Open
- In Progress
- Waiting for User
- Resolved
- Closed
